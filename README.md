## 👋 About me

I'm **Valentin**, a Python developer.
I started with small scripts that killed routine — Excel reports, parsing, automation.
They grew into Telegram bots, then into services with databases, Docker and deploys.

Now I build **bridges for AI coding tools**: relays and key managers that let different
AI stations work inside the editor I actually use. I like tools that start with one click
and don't trust magic without logs.

## 🔴 Project

| | |
|---|---|
| **[ClodKey](https://github.com/Apex4Coder/ClodKey)** | Tray key manager for Claude CLI + a relay that lets Claude CLI-format stations (e.g. agentrouter.org) work in Zoo Code / Roo Code. Its model check shows when the station turns on Claude Opus. |
